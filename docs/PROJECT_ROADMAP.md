# TB-Screen AI Project Roadmap

## Objective

Build a state-level AI-assisted tuberculosis screening system using chest X-ray analysis, explainability, and automated report generation.

## Development Phases

### Phase 1 — Prototype

- Project setup
- Public dataset preparation
- DenseNet121 training
- U-Net lung segmentation
- YOLOv8 localization
- Grad-CAM visualization
- Streamlit prototype
- FastAPI integration

### Phase 2 — Clinical Integration

- DTO dataset fine-tuning
- Performance evaluation
- Calibration
- District deployment

### Phase 3 — Production Readiness

- Docker deployment
- Offline mode
- Security improvements
- Monitoring
